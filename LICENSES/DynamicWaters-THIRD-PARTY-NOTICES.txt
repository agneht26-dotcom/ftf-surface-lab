# Dynamic Waters 13.1.1 — Third-party & File Notices (FTF Surface Lab C++ Port)

Dynamic Waters (`AdamNew`) is licensed under the **Mozilla Public License 2.0** (`DynamicWaters-MPL-2.0.txt`).
The C++ preview implementation in FTF Surface Lab adapts algorithms and data from Dynamic Waters 13.1.1
(`src/dynamic_waters_*.hpp`, `src/dynamic_waters_*.cpp`, and `assets/dynamicwaters/`) while retaining each
upstream component's licence and attribution. The rest of FTF Surface Lab is a separate "Larger Work" under
MPL-2.0 Section 3.3.

## File mapping in FTF Surface Lab

| FTF Surface Lab path | Upstream source & adaptation | Licence |
|---|---|---|
| `src/dynamic_waters_config.hpp` | Dynamic Waters `Config` / TOML schema & hash state | MPL-2.0 (`DynamicWaters-MPL-2.0.txt`) |
| `src/dynamic_waters_noise.hpp` | Dynamic Waters FastUtil / Minecraft 1.21.1 noise helpers | MPL-2.0 (`DynamicWaters-MPL-2.0.txt`) |
| `src/dynamic_waters_hydrology.hpp`, `.cpp` | Dynamic Waters `HydrologyManager`, `LakeHollows`, `ShoreSkin`, `RiverbankPalettes`, `WaterPlants`, `Boulders` | MPL-2.0 (`DynamicWaters-MPL-2.0.txt`) |
| `src/dynamic_waters_basin.hpp`, `.cpp` | Dynamic Waters `BasinTile`, `WatershedPath`, `WatershedLake`, `ChannelForm`, plus `dynamicwaters-asyncrivers` scheduling | MPL-2.0 + MIT (see below) |
